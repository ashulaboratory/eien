# Eien — 永遠の仲間とのSNS

> 学校生活や部活動など、長い時間を共に過ごしてきた「永遠の縁」のある仲間と、
> 安心して長く使い続けられるクローズドなSNSをつくります。

---

## 背景

高校のクラスメイトや、大学で所属していたサークル。近い距離で長く過ごしてきた人とも、いつか別れの時は訪れる。
私は2026年3月に、五年間通った高専を卒業した。五年間ずっと同じ教室で顔を合わせてきたクラスメイトは、これからも永く付き合っていきたい人ばかりだ。けれど、それぞれが進学や就職で別々の道に進み、しばらく顔を合わせられない仲間も少なくない。
それでも、たまにでいいから、あの人たちが今どう過ごしているのかは知っていたい。あの五年間を、共に過ごした仲間のことを、忘れたくないからだ。あの関係を「思い出」にしたくない。今もまだ続いている、現在進行形の縁でいたい。結婚や出産の節目があったら祝ってあげたい。たまに見かけて、元気そうだなと思えるだけでいい。

そういう願いを叶える手段として、真っ先に思い浮かぶのはSNSだ。SNSで繋がっていればわざわざ連絡を取り合わなくても、相手の投稿から日常を知ることができる。

けれど、いざ使おうとすると、既存のSNSにはどれも弱点がある。
LINE は連絡用には便利だが、流れていくチャットの中で「近況をふらっと眺める」ような使い方には向かない。Instagram は不特定多数への発信を前提にしていて、フォロワーがどんどん広がっていく。「あの五年間の仲間だけが集まる場」とは設計が違う。X に至っては、公開と拡散が前提で、タイムラインに知らない人の投稿やノイズが絶えず流れてくる。
そして何より、SNSはどれも中毒性が強い。本来繋がりたかった相手よりも、見知らぬ誰かに時間を奪われていく。私自身、SNSから距離を置くことで、リアルの時間でできることが確かに増えたと感じている。
同じように考えて、SNSそのものをやめてしまった友人もいる。けれど皮肉なのは、そういう「SNSをやめた人」とは、既存のSNSでは繋がれなくなるということだ。リアルを大事にしたい人ほど、長く付き合いたい仲間との接点を失っていく——既存のSNSはそういう構造になってしまっている。
ないなら、自分で作ろうと思った。中毒性に依存せず、リアルの時間を奪わず、それでも長く繋がっていられる場所を。
「広く浅く」ではなく「狭く長く」を価値にしたSNS、Eien を。

## コンセプト
高校、大学、部活、サークル、職場——場所も期間も人それぞれだが、「長く同じ時間を過ごしてきた仲間」を持つ人は多い。Eienは、そうした人たちのための場所である。
**永遠の仲間とのSNS**
もし、かつてのクラスメイトと利用するならこのSNSは卒業アルバムの現在進行形となる。卒業アルバムが本棚の奥で過去を静かに映し出す存在だとすれば、Eienは同じ顔ぶれをそのままオンラインに移し、それぞれの人生のマイルストーンが流れていく場にする。

- 招待制で、メンバーを固定する。 不特定多数を相手にせず、「長く同じ時間を過ごしてきた仲間」だけが集まる場を作る。
- 通知を最小限にする。 毎日のようにユーザーをSNSに引き戻すための仕組みは置かない。リアルの時間を侵食しないことを優先する。
-「深く長く」使える体験を目指す。 投稿頻度や滞在時間を煽る設計を排し、たまにふと開く、という距離感を保てるようにする。

## ターゲットユーザー

- 学校・部活・サークルなどで一緒に時間を過ごしてきた、これからも縁が続いていく友人グループ。
- 既存SNSの不特定多数性に疲れ、「気の置けない仲間とだけ繋がれる場」を求めている人。

## ゴール

本プロジェクトでは、以下の状態をもって「成功」と定義します。

- 招待リンクから利用可能な形で本番環境にデプロイし、一般公開する。
- ポートフォリオとして、設計意図・技術選定・実装の判断を自分の言葉で説明できる品質に仕上げる。

## 学習目標

Web開発を主目的としており、以下4領域を一貫して経験することを重視します。

- **フロントエンド**：React / Vue 等を用いたUI構築・状態管理
- **バックエンド**：API設計、認証認可、ビジネスロジック実装
- **DB・データモデリング**：テーブル設計、リレーション、クエリ最適化
- **インフラ・デプロイ・CI/CD**：クラウド上での公開と自動デプロイの仕組み構築
