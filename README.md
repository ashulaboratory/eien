# Eien — 永遠の仲間とのSNS

> 学校生活や部活動など、長い時間を共に過ごしてきた「永遠の縁」のある仲間と、
> 安心して長く使い続けられるクローズドなSNSをつくります。

---

## 背景

既存のSNSの多くは「不特定多数とのつながり」を前提に設計されており、ノイズの多さ、信頼関係の希薄化、利用疲れといった課題が指摘されています。

一方で、「本当に長く付き合っていく仲間」と、気軽に・安心して・長期的に使える場は意外と見つかりません。学生時代の友人や部活仲間といった "縁の続く人" と、落ち着いて交流できる専用の場をつくりたい、というのが本プロジェクトの出発点です。

加えて、開発を通じてWebアプリケーションをフロントからインフラまで一貫して経験し、就職活動にも活かせるポートフォリオとして仕上げることを目的としています。

## コンセプト

**「永遠の仲間とのSNS」**

- 学校時代の友人、部活の仲間など、長く続く関係を前提としたクローズドな設計。
- 招待制でメンバーを限定し、信頼関係をベースにした安心できる場を提供する。
- 不特定多数を相手にせず、「深く・長く・落ち着いて」使える体験を目指す。

## ターゲットユーザー

- 学校・部活・サークルなどで一緒に時間を過ごしてきた、これからも縁が続いていく友人グループ。
- 既存SNSの不特定多数性に疲れ、「気の置けない仲間とだけ繋がれる場」を求めている人。

## ゴール

本プロジェクトでは、以下の状態をもって「成功」と定義します。

- 招待リンクから利用可能な形で本番環境にデプロイし、一般公開する。
- ポートフォリオとして、設計意図・技術選定・実装の判断を自分の言葉で説明できる品質に仕上げる。

## 学習目標

Web開発を主目的としており、以下4領域を一貫して経験することを重視します。

- **フロントエンド**：React / Vue 等を用いたUI構築・状態管理
- **バックエンド**：API設計、認証認可、ビジネスロジック実装
- **DB・データモデリング**：テーブル設計、リレーション、クエリ最適化
- **インフラ・デプロイ・CI/CD**：クラウド上での公開と自動デプロイの仕組み構築
